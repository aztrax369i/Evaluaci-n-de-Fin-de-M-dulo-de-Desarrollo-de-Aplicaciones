# Evaluaci-n-de-Fin-de-M-dulo-de-Desarrollo-de-Aplicaciones

Implementación de funciones en JavaScript y sus pruebas unitarias utilizando el framework Jest.

🚀 Funcionalidades Implementadas (calculator.js)

* Operaciones básicas (add, subtract, divide, multiply): Suma, resta, división y multiplicación de dos números.

* Promedio (promedio): Calcula el promedio de cinco números.

* Factorial (factorial): Calcula el factorial de un número entero positivo (retorna null para números negativos o decimales).

* Suma de números naturales (sumaNaturales): Suma cinco números validando que todos sean enteros positivos mayores a cero (retorna null en caso contrario).

* Fórmula general (formulaGeneral): Obtiene las raíces reales (x1, x2) de una ecuación cuadrática (retorna null si el primer coeficiente es cero o si las raíces son imaginarias).

⚙️ Instalación y Ejecución

1. Instalar dependencias:

   ```
   npm install
   
   ```

2. Ejecutar todas las pruebas:

   ```
   npm test
   
   ```

3. Ejecutar solo las pruebas de la calculadora:

   ```
   npx jest calculator.test.js
   
   ```
